# 上班激励计时器 (MCTimer)

一个苹果设计风格的桌面小组件：看看每一秒赚了多少钱，下班更有盼头。

![screenshot](assets/icon.png)

## 使用

双击 **`上班激励计时器.exe`** 即可运行，无需安装 Python。

- 小窗始终置顶，**按住任意空白处拖拽**可移动位置（位置会被记住）
- 点击右上角 **齿轮** 打开设置（窗口内滑动切换）：
  - **上班时间 / 下班时间**：格式 `HH:MM`；结束时间早于开始时间视为跨天夜班（如 `22:00` → `06:00`）
  - **日薪（元）**：每天的总收入
  - **每周工作日**：点选周一~周日，未选中的日子显示"今天不上班"
- 点击 **─**（最小化）把窗口**收缩成小圆球**：只占 64px，显示状态点 + 倒计时
  （绿=进账中 / 橙=待上班 / 灰=已下班或休息）；**点击圆球**展开回完整窗口；
  圆球同样可拖拽，折叠状态在重启后保持
- 点击 **✕** 退出

## 窗口显示内容

| 区域 | 说明 |
|---|---|
| 大数字倒计时 | 上班前 = 距上班；上班中 = 距下班（每秒刷新） |
| 进度条 | 今日工作进度百分比 |
| 今日 | 今日已赚工资，**精确到秒实时跳动**（¥0.0000 四位小数） |
| 本月 / 总计 | 按历史记录累计，含今日实时金额 |
| 底部 | 每秒进账速率，如 `每秒 +¥0.0104` |

## 数据与统计口径

- 数据保存在 `%APPDATA%\MCTimer\`（`config.json` 配置、`history.json` 历史）
- **总计自首次使用之日起累计**；当天工作结束后金额即被"冻结"入历史
- 应用未运行的工作日，按当时日薪自动补记（整日计入）
- 修改日薪只影响之后的日子，不回溯改写已冻结的历史

## 从源码构建

```bash
pip install pyinstaller pillow
python make_icon.py      # 生成 assets/icon.ico（可选，build.bat 会自动执行）
build.bat                # 产出 dist\MCTimer.exe 并复制为 上班激励计时器.exe
```

源码仅一个文件 `mctimer.py`，纯标准库（tkinter），逻辑自测：`python mctimer.py --selftest`。

## 备注

- PyInstaller 单文件 exe 首次启动需 1~2 秒解压，属正常现象
- 个别杀毒软件可能对 PyInstaller 打包的 exe 误报，可添加信任
- 开机自启：把 exe 快捷方式放入 `Win+R → shell:startup` 打开的文件夹
